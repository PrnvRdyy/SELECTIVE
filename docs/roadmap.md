# Roadmap

## V1 (Current) — MVP

- [x] Project setup (TypeScript + React + Vite + Manifest V3)
- [x] Settings system with local storage
- [x] Extension popup with toggle controls
- [x] YouTube Shorts blocking
- [x] YouTube Home Recommendations blocking
- [x] Instagram Reels blocking
- [x] Instagram Explore blocking
- [x] Blocked screen UX
- [x] Local analytics tracking
- [ ] Comprehensive manual testing
- [ ] Chrome Web Store submission

## V1.1 — Polish

- [ ] Refined CSS selectors based on real-world testing
- [ ] Better blocked screen design
- [ ] Keyboard shortcut to toggle blocking
- [ ] Badge icon showing active block count
- [ ] Improved analytics dashboard in popup

## V2 — More Sites

- [ ] TikTok For You page blocking
- [ ] Reddit Popular/Home feed blocking
- [ ] LinkedIn Feed blocking

## V3 — Advanced Features

- [ ] Custom blocking rules (user-defined CSS selectors)
- [ ] Time-based schedules (e.g., block Shorts during work hours)
- [ ] Temporary unlock (allow for 5 minutes)
- [ ] Usage limits (e.g., allow 10 minutes of Reels per day)
- [ ] Export/import settings

## Future Considerations

These are ideas that depend on user feedback and adoption:

- Cross-device sync (chrome.storage.sync)
- Firefox/Edge support
- Community-created rule packs
- Advanced analytics with usage insights
- Android support (separate project)

## Non-Goals

These will NOT be built:

- AI-powered blocking
- Payment/subscription system (until justified by usage)
- Cloud backend
- Social features
- Gamification
