# Supported Sites

## Currently Supported

### YouTube (`www.youtube.com`)

| Feature | Block Type | Description |
|---------|-----------|-------------|
| Shorts | CSS hiding + route block | Hides Shorts shelves, sidebar tab, and blocks /shorts/ navigation |
| Home Recommendations | Route block + overlay | Blocks the home page feed, other pages unaffected |

**Unaffected functionality:** Search, subscriptions, watch pages, library, playlists, channels

### Instagram (`www.instagram.com`)

| Feature | Block Type | Description |
|---------|-----------|-------------|
| Reels | CSS hiding + route block | Hides Reels navigation and blocks /reels/ navigation |
| Explore | CSS hiding + route block | Hides Explore navigation and blocks /explore/ navigation |

**Unaffected functionality:** Feed posts, stories, DMs, profile, settings

## Planned Sites

- Reddit (Popular/Home feed)

- Facebook (Reels, suggested content)
- Twitter/X (Recommendations, For You)
